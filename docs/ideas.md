# Idea Board

## Screenshot Capture
- **Remember last area** — When taking a screenshot, remember the previously selected region so the user doesn't have to reselect it every time.
- **Predefined areas and sizes** — Allow users to define preset capture regions/sizes and assign hotkeys to them for continuous, quick screenshots without needing to manually select an area each time.
- **Hold hotkey to record video** — Hold down a hotkey to start recording video of the selected area, and release to stop recording.

## Post-Capture
- **Auto-copy in multiple formats** — Copy the screenshot to clipboard in multiple formats (PNG, base64 data URI, markdown image link) so devs can paste directly into code, docs, or chat.
- **Annotation/markup** — Dev-oriented annotation tools: code arrows, redaction, numbered callouts, and text labels for quick markup before sharing.
- **Instant shareable link** — One-click upload to a shareable URL with zero config, for fast sharing in Slack, PRs, or bug reports.
- **Window/element-aware snapping** — Detect window boundaries automatically so the selection snaps to edges without pixel-hunting.
- **History/gallery with search** — Searchable gallery of past captures so you can find "that screenshot of the error modal from last Tuesday" without digging through files.
